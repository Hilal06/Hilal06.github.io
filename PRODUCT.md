# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Tech recruiters, hiring managers, and prospective clients looking to evaluate or hire a Full-Stack / Frontend Developer.

## Product Purpose
Provide an immersive, highly crafted personal portfolio website showcasing professional skills, interactive projects, live GitHub repository metrics, and direct contact capability.

## Positioning
High-crafted interactive personal portfolio featuring cutting-edge Svelte 5 Runes architecture, dynamic GSAP motion & Lenis smooth scrolling, live GitHub REST API data integration, and crisp dark-mode glassmorphic aesthetics.

## Operating Context
Evaluated on desktop and mobile web browsers by tech recruiters during candidate screening, hiring managers reviewing project quality and codebase standards, and clients checking live project demos.

## Capabilities and Constraints
- Svelte 5 with native Runes (`$state`, `$derived`, `$effect`, `$props`)
- Tailwind CSS v4 design tokens in `src/app.css` (`@theme`)
- Dynamic GSAP timelines with proper cleanup on component unmount
- Live GitHub API fetching for stars, forks, and repo status (`src/lib/github.ts`)
- Web3Forms integration for direct email contact
- Responsive modal dialogs for project details and resume preview

## Brand Commitments
- Sleek, modern Dark Mode aesthetic with subtle glassmorphic styling
- Smooth micro-interactions and scroll animations
- Fast performance and clean accessibility

## Evidence on Hand
- Curated project showcase in `src/data/projects.json`
- Tech stack marquee icons in `src/components/SkillsMarquee.svelte`
- Live GitHub API endpoint integration

## Product Principles
1. Craft & Performance First: Fast loading and responsive UI with zero slop.
2. Dynamic & Interactive: Subdued yet impactful motion using GSAP and smooth scrolling with Lenis.
3. Live Data Transparency: Live repository stats fetched dynamically via GitHub REST API.
4. Clean Architecture: Strict type safety with Svelte 5 runes and clean Tailwind v4 custom theme tokens.

## Accessibility & Inclusion
- High contrast dark mode UI elements.
- Semantic HTML tags and keyboard navigable modals.
